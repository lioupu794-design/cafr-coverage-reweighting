# Results

All numbers here are means over seeds 2026, 2027 and 2028 on the PEMS08
topology-support setting, produced by `src/run_official_stpgnn_cafr.py`
with the commands in the top-level README.

| file | content |
|---|---|
| `strategy_comparison_baselines.csv` | ERM, Inverse Freq, Gap Reg (0.1/0.5/1.0), Smooth DRO (0.1/0.5/1.0), Random-CAFR (lambda 4) on the STPGNN backbone — 63 columns, including per-horizon metrics |
| `summary_by_run.csv` | the same runs, one row per seed, before averaging |
| `cafr_lambda_sweep.csv` | CAFR at lambda in {1, 2, 4, 8} and the validation-selected VG-CAFR; five columns only, see the note below |
| `training_log.txt` | stdout of the baseline run (per-run `[result]` lines) |

This folder covers the backbone check on STPGNN. The Graph WaveNet rows of
Table 4 in the paper come from the same script with `--model official_graphwavenet`
and are regenerated by the same two commands.

Columns shared with the paper:

* `overall_mae_mean` → Overall MAE
* `low_coverage_mae_mean` → Low MAE
* `gap_mean` → Gap
* `delta_*_vs_erm` → the change relative to the ERM row of the same run

## Note on `cafr_lambda_sweep.csv`

This table was assembled from the run summaries recorded when the sweep was
launched, so it carries the five aggregate columns only; the per-seed rows of
that sweep were not archived. `num_runs = 3` refers to the three seeds, and
`lambda_weight = "selected per seed"` marks the VG-CAFR row, whose strength is
chosen on validation data and is therefore not a single constant. The full
63-column schema is produced again by re-running the CAFR command in the
top-level README.
